<11/29 변경 사항 정리>
1. DB 변경 (기존 H2 db에서 MySQL로 변경)
2. 이메일 인증 관련 추가 사항 - 이메일 인증 남은 시간 표시(카운트다운?)
3. 이메일 인증 관련 수정 사항
  - 기존: 메일로 받은 링크를 타고 웹사이트에 접속하여 인증을 마치면 회원가입 페이지로 이동(탭이 2개가 됨)
  - 수정: 링크를 누르면 인증되었다는 문구를 화면에 출력 + 원래 탭에서 자동 페이지 이동
4. 비로그인 사용자 접근 제한 관련 수정 사항
  - 로그인 하지 않은 사용자가 (+더보기) 버튼을 누르면 이용할 수 없는 서비스라는 문구를 출력 + 로그인 페이지로 이동
  - 로그인 하지 않은 사용자는 (글 작성) 버튼이 아예 보이지 않게 함
